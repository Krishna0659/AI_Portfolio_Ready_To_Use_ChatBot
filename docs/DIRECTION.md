# Profile workspace direction

User-selected purpose and composition: denser dashboard, with sources, import status, draft and approved versions easily accessible. Operate mode, code-led. No image comp was approved.

Design Taste dealt the Framed Sheet style (root `.taste-skill/direction.json`). Impeccable seed `seed:ab378d875286c2d8` was degraded: the roll service supplied no challenger boards even after a network-enabled retry. The complete Impeccable visual decision-page process was not performed; do not represent this as a fully skill-approved visual direction.

First viewport: compact navigation, honest source/import/fact/version counts, source rows, current-profile state, activity, and disabled/mock delivery state. No fictitious metrics. Brand mark is an outlined P, with IBM Plex Sans served locally, a low-chroma blue-gray frame and white working sheet. Teal is used sparingly for review state and focus.

Signature interaction: select a source, read its evidence, explicitly add it to the draft, edit, save, and approve. Imported material remains separate from the profile until selected. A source selection has durable active styling and `aria-pressed` state.

Responsive target: 1440px dashboard and 390px stacked workspace without horizontal overflow. Mobile keeps account sign-out in Settings. Pending public-launch accessibility, security and lifecycle work is tracked separately in IMPLEMENTATION_STATUS.md.
